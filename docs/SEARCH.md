# 查找书籍

在右上角打开搜索，输入关键词，不必输入完整书名。点击输入框右侧的筛选图标，可选择 **全部、书名、作者、标签、书籍 ID**；每个入口分别保留搜索范围。

## 发现：联网查书名、作者与标签

「全部」会同时查询书名、作者与标签，合并去重。选择「标签」可直接输入 `奇幻`、`女性视角` 等标签，只匹配标签；选择「作者」或「书名」时只查询对应范围。ID 需要输入完整编号。向下滚动可继续加载结果；返回后保留输入内容和已加载结果。

也可从 **发现 → 分类与排序 → 标签** 点选标签进入书单。标签搜索接口的前 20 项之后，会从可分页的书目元数据中继续筛选，不把接口的截断数量当作总数。

## 书架、本地：查标签和自定义分类

书架默认检索联网收藏；开启「合并书架」后，也检索已缓存正文的联网书、本地原书与合订本。本地入口只检索导入书籍。支持：

- 书名片段、作者、书籍编号与已有标签。
- 本地入口及合并书架中的本地项可检索自定义分类名。
- 多个关键词，例如 `川原 冒险`，要求每个词都能在这本书的元数据中找到。
- `#标签`，例如 `#校园 川原`，其中「校园」只匹配标签或分类，不匹配书名。

英文不区分大小写，兼容全角字母、数字和常见分隔符，例如 `刀剑神域` 可匹配「刀剑・神域」。这里的模糊匹配是关键词包含匹配，不进行错字纠正或拼音推断。

详情页的标签可以点击，打开该标签的分页书单，与作者作品页使用同一套列表与加载交互。无网时只显示本机可离线阅读的已知书籍。标签来自服务元数据，接口未提供时不从书名或简介猜测。

## 合并书架：按来源筛选

书架筛选菜单提供两个独立条件：阅读状态和书籍来源。来源可选全部、本地导入、已缓存、在线收藏；其中「已缓存」指已有正文缓存的联网书，「在线收藏」包含已收藏的联网书。两个条件可以组合，立体书架、列表与书架搜索共享来源范围。关闭合并书架后恢复独立书架，不受此前来源筛选影响。离线和阅读器模式仍只展示可离线阅读的书。
